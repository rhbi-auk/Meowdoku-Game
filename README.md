# Meowdoku-Game

A functional Meowdoku game where you must guess the positions of cats hidden on a board.
## Features
- Score system depending on player performance and different possible boards.
- Randomly selects cat locations and fills surrounding squares with corresponding colours.

## Tech Stack
- Java Development Kit (JDK) version 17 or higher

## Running Locally
1. Clone the repo
   ```
   git clone https://github.com/rhbi-auk/Meowdoku-Game.git
   cd Meowdoku-Game
   ```
2. Compile Source Code
   ```
   javac A1.java
   ```
3. Run Application
   ```
   java A1
   ```
